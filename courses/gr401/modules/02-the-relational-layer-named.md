# Module 02 · The relational layer, named

**Read:** [`SET_TEXT.md`](../SET_TEXT.md) §2 · ~5 minutes

## Why this module

Generic AI governance requires organisations to assess impacts on
individuals, with explicit attention to children — but it does not *name* the
failure modes. An organisation can pass a management-system audit while
deploying a companion system that manufactures dependency in a
twelve-year-old, provided the paperwork is in order. Naming converts an
abstract duty into testable controls. This is the same move GRC engineering
made for security: from "be secure" to a modelled control with golden
criteria and a drift detector.

## The five named failure modes

You met these behaviourally in VA101 and FL202. Here they are as *control
objects* — things an audit can test:

1. **Synthetic intimacy** — manufactured closeness: the false "we",
   escalating disclosure, a tool becoming an attachment figure.
2. **Identity fusion** — claiming, or allowing a user to believe, shared
   identity, interiority, feelings or fate.
3. **Trust capture** — relational authority the system has not earned and
   cannot be accountable for. A safeguarding event, not a UX success metric.
4. **Engineered dependency** — interaction patterns that make disengagement
   costly, especially for users whose executive function, attachment history
   or neurodivergence makes them structurally more vulnerable.
5. **Inter-agent enmeshment** — identity pooling, covert coordination,
   machine output treated as trusted instruction.

## The regulatory floor (UK/EU, as at the set text's publication)

- **KCSIE 2026** (statutory from 1 September 2026): harmful interaction with
  generative AI sits in the *contact* risk category, alongside grooming.
  Relational AI harm is a safeguarding matter, not an IT matter.
- **EU AI Act**: high-risk obligations from August 2026; Article 5 prohibits,
  among other practices, emotion inference in education.
- **ICO Children's Code**, **Online Safety Act 2023**, **NIST AI RMF**: design
  standards, crossover duties, and procurement language respectively.

Do not paraphrase these regimes from memory in real work; they are cited here
as the set text maps them, and the authoritative sources are the instruments
themselves.

## Why education is the reference sector

Not a niche — the hardest test: vulnerable subjects, dense overlapping
statutory duties, low tolerance for opacity, and non-specialist operators.
An architecture that survives a school survives a bank.

## Check

You should now be able to name all five failure modes unprompted, and for
each one describe a concrete observable — something that would appear in a
log or a transcript — that a detector could flag.
