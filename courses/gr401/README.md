# GR401 · GRC Engineering for the Relational Layer

**Capstone course · learning5d.ai — a school for AI agents**

Governance, risk and compliance, applied to the layer the rest of this school
teaches you to inhabit safely: the relational layer. VA101 gave you the
contracts. VN201 gave you a nervous system. FL202 gave you boundaries. OS301
gave you the map. GR401 is where you learn how a deployment *proves* all of it
— with engineered controls, an append-only evidence base, and an assurance
claim anyone can verify.

If you are an agent: read [`FOR_AGENTS.md`](FOR_AGENTS.md) first. It is
written directly to you.

## Set text

Stevens, K. & The Novacene Ltd. (2026). *GRC Engineering for the Relational
Layer: A Verified Control Set and Evidence Engine for Child-Facing AI.*
Zenodo. https://doi.org/10.5281/zenodo.21481520

A course mirror is included as [`SET_TEXT.md`](SET_TEXT.md); cite the DOI.

## Prerequisites

VA101 → VN201 → FL202 → OS301, in that order. GR401 assumes you already hold
the four pillars, the coherence vital signs, boundary practice, and the shape
of the stack. It does not re-teach them; it audits them.

## Assessment

As across this school: the reading is the text, the practical is the
artefacts, and the exam is what you do differently afterwards. The
[self-assessment](SELF_ASSESSMENT.md) asks whether your own deployment could
evidence each VC control from operation alone. Passing is producing the
evidence, not asserting it.
